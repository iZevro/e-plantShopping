# e-plantShopping - Paradise Nursery Shopping Application

## Overview
**e-plantShopping** is a React-based e-commerce application for **Paradise Nursery**, an online store for houseplants. The application allows users to browse houseplant categories, add items to a shopping cart, manage item quantities, and view real-time totals using Redux state management.

## Key Features
- **Landing Page**: Introduction to Paradise Nursery with a "Get Started" call-to-action.
- **Product Catalog**: Categorized houseplant listings displaying thumbnails, names, prices, and dynamic "Add to Cart" actions.
- **Shopping Cart**: Real-time shopping cart with item quantity updates, line-item sub-totals, overall total calculation, and item removal.

## Tech Stack
- **Frontend**: React, JavaScript (ES6+), HTML5, CSS3
- **State Management**: Redux Toolkit
- **Build Tool**: Vite
